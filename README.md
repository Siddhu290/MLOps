# MLOps-Practical-Exam — Wine Classification

One folder per practical, one branch per member. Nobody edits files outside their own folder,
so the pull requests never conflict.

| Practical | Folder | Branch | Lab manual |
|---|---|---|---|
| 1 Git version control | `practical-1-git/` | `practical-1` | Expt 2 |
| 2 DVC dataset versioning | `practical-2-dvc/` | `practical-2` | Expt 3 |
| 3 Data pipeline | `practical-3-pipeline/` | `practical-3` | Expt 4 |
| 4 Feast feature store | `practical-4-feast/` | `practical-4` | Expt 5 |
| 5 MLflow tracking and registry | `practical-5-mlflow/` | `practical-5` | Expt 6 |

Every folder runs on its own: practicals 4 and 5 carry their own copy of the
Expt 4 pipeline scripts to produce the feature CSV they need.
